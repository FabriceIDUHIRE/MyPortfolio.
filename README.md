# Fabrice Iduhire — Portfolio

Built from the Figma design with React, Vite and Framer Motion.

## Edit your links
Open `src/content/site.ts` and fill in `bookCall`, `resume` and `linkedin`.
Buttons that use an empty link stay hidden.

## Add your photos
Put them in `public/images/` (see the README in that folder for the file names).

## Edit case study text
Everything lives in `src/content/cases.ts`.

## Run it locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository on [vercel.com](https://vercel.com/new). Vercel detects Vite automatically,
no settings needed. Every push to `main` goes live on its own.
